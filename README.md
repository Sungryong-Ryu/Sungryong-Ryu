## ABOUT

순수회화를 기반으로 작업하는 작가이자 최근 시집을 출간한 시인입니다.  
회화와 시에서 출발한 감각을 디자인과 개발로 확장하며, 서로 다른 매체가 만나는 지점을 탐구합니다.

I am a painter and poet working across visual art, language, design, and technology.
